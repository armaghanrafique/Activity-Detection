Camera connection

Before you configure a camera

  • An IP camera that supports RTSP or ONVIF (most modern IP / PoE cameras do).
  • An Ethernet cable from the camera to the laptop, or both on the same switch / router.
  • Power to the camera — either a PoE switch/injector, or the camera's own power adapter.
  • The camera's login (username and password) set in the camera's own app or web page.
  • The camera and laptop must be on the same subnet (see the setup guide for how to set this).
  • Know whether the camera uses RTSP (port 554) or HTTP/MJPEG (port 80) — or leave Protocol on Auto detect.
If the camera is already installed on your network with a known IP and login, you can skip straight to the form and press Test connection.

1. Connect the Ethernet cable

  1. Plug one end of the Ethernet cable into the camera's LAN / network port.
  2. Plug the other end into the laptop's Ethernet port (or into a switch / router both devices share).
  3. Power the camera on. Wait about 30 seconds for it to boot.
  4. If using a direct laptop-to-camera cable with no router, a link light on the port confirms the physical connection.

2. Put the laptop and camera on the same subnet

  1. Most cameras ship with a default IP such as 192.168.1.64 (Hikvision) or 192.168.1.108 (Dahua) — check the camera's manual or label.
  2. On the laptop open Settings > Network & internet > Ethernet > IP assignment > Edit.
  3. Choose Manual, turn on IPv4, and set an IP in the same range as the camera, for example 192.168.1.10.
  4. Set Subnet mask to 255.255.255.0. Leave Gateway blank for a direct connection.
  5. Save. The laptop and camera can now talk to each other.
If a router / DHCP is in charge, both devices get their IPs automatically — skip the manual step and just find the camera's assigned IP below.

3. Find the camera's IP address

  1. Easiest: press Scan network below — it auto-discovers ONVIF cameras on your LAN and lets you click one to fill the IP.
  2. Or read the IP from the camera vendor's tool (Hikvision SADP, Dahua ConfigTool, Reolink app, etc.).
  3. Or check the router's client list for the camera's IP.

4. Configure the connection here

  1. Enter the camera's IP address and its username / password.
  2. Leave Port, Protocol, and Stream path as-is for Auto detect, or set them if you know them.
  3. Advanced: paste a complete Full stream URL (e.g. rtsp://user:pass@192.168.1.64:554/Streaming/Channels/101) to override every other field.
  4. Press Test connection. On success a preview frame appears — then press Start detection.
If Test fails, confirm the camera is powered, both devices ping each other, and the login is correct. RTSP uses port 554; HTTP/MJPEG uses port 80.
